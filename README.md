# AKAN-NAME-GENERATOR# Akan Name Generator

## Description
A simple web application that calculates the day of the week a user was born and assigns an Akan name based on their gender, following Ghanaian cultural naming traditions.

## Author
samwel mwangi

## Setup Instructions
1. Clone or download the repository
2. Open `index.html` in your browser
3. Enter your birth details and gender

## BDD (Behavior Driven Development)
- User enters birth date and gender
- Application validates the input
- Application calculates day of the week
- Correct Akan name is displayed
